# Decisions

- Keep the product site dependency-free: plain HTML, CSS, and JavaScript remain enough for the current public foundation.
- Label the interactive router as a simulation and use future-tense or roadmap labels for the engine, integrations, scheduling, and managed plans until each exists.
- Use GitHub as the current source of truth for the project brief, roadmap, discussions, issues, security reporting, and license.
- Publish through GitHub Pages first so the repository and live source stay aligned without adding hosting infrastructure.
- Do not use `gethotpotato.com` or its email domain: that domain belongs to an unrelated active product. A permanent product name and domain need separate diligence.
