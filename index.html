02 / HOW IT WORKS

Routing logic
you can actually read.

The application supports conditional rules, existing-owner preference, and weighted assignment. This sketch illustrates the idea; the repository documents the actual rule format.

⌘ Rule sketchPSEUDOCODE
// enterprise inbound
when(lead.employees >= 500)
  .territory(lead.region)
  .prefer("account_owner")
  .fallback("weighted_round_robin")
  .require("calendar_available")
  .route();
Illustrative pseudocode · see the application for its rule format
